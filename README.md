NekoPLUS is a NeoForge addon mod for AnvilCraft. It adds extra blocks, items,
UI tools, recipes, and gameplay extensions for the NekoPLUS feature set.

## Requirements

- Minecraft/NeoForge 26.1.2
- Java 25
- AnvilCraft 1.6.0 or newer

## Development

Use the Gradle wrapper from the project root:

```powershell
./gradlew.bat compileJava
./gradlew.bat runData
./gradlew.bat test
```
