# 粒子稳定器

<ItemImage id="nekoplus:particle_stabilizer" scale="8" />

用于稳定粒子，或者从空气中提取资源。

## 能耗与超频

粒子稳定器在冷却中状态时，消耗32kW的电能，粒子稳定器在冷却完毕状态时，消耗32kW的电能。

粒子稳定器拥有[超频](overclocking.md)功能。

在不超频的情况下，粒子稳定器需要30秒(6000 tick)来冷却完毕，仅在冷却中状态的粒子稳定器可以超频，每一超频等级都额外消耗32kW电能，增加一倍的冷却速度。

## 获取资源

当粒子稳定器的输入槽放置有<ItemLink id="nekoplus:air_filter" />时，可从空气中获取资源，不同的维度空气拥有不同的资源设定。
