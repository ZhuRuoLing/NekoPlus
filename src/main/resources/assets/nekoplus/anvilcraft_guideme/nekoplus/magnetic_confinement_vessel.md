# 磁约束容器

<ItemImage id="nekoplus:magnetic_confinement_vessel" scale="8" />

用于收容砧子。

# 砧子类型
## 不稳定砧子
不稳定砧子几乎无法做任何事情，仅能用于当做合成原料。

使用<ItemLink id="nekoplus:particle_stabilizer" />稳定高速运动的铁砧获取。

## 稳定砧子

稳定砧子可被填充入<ItemLink id="nekoplus:anvilon_emitter" />中，起到类似于燃料的作用。

与<ItemLink id="nekoplus:stabilize_powder" />和装有不稳定砧子的磁约束容器一同混合获取。

## 纠缠砧子
没做。
