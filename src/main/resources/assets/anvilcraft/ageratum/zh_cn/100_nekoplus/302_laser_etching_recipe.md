# 激光蚀刻配方

<structure id="./structures/laser_etching_recipe.snbt"/>

图中激光束用于提供 64 激光能级。

激光蚀刻配方可用于生产合成 <ref item="nekoplus:integrated_chip_circuit_board"/> 等物品所需的原料。

激光蚀刻配方所使用的冲压平台需要被至少 64 能级的激光束照射，但不要求必须是高能激光器。

其余部分与基本物品处理/冲压相同。
