# Enhancement Modules

<item id="nekoplus:modular_enhancement_template"/>

Gives equipment the ability to install enhancement modules. Use it together with an <ref item="nekoplus:advanced_processor"/>.

<item id="nekoplus:enhancement_module_base"/>

The Enhancement Module Base is the base material for every craftable enhancement module.

<item id="nekoplus:anti_gravity_module"/>

When installed, provides creative flight.

<item id="nekoplus:titanium_crystal_module"/>

When installed, each module increases the original attack damage by 30%. Stacks with multiple modules.

<item id="nekoplus:hologram_projector_module"/>

Not finished.

<item id="nekoplus:mechanical_heart_module"/>

When installed, each module increases the original maximum health by 30%. Stacks with multiple modules.

<item id="nekoplus:exoskeletal_leg_frame_module"/>

When installed, each module increases the original movement speed by 20%. Stacks with multiple modules. It also adds 0.5 blocks of step height and 30% jump height, which do not stack.
